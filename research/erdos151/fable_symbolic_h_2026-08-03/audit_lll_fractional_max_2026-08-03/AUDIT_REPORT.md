## 1. Theorem A1: hostile reconstruction

Let `t=t_max`.  Color vertices independently and uniformly with `k` colors.
For each triangle `T`, let `A_T` be the event that its three vertices have one
color.  Then

`Pr(A_T) = k * k^{-3} = k^{-2}`.

The event is a function only of the three vertex-color variables on `T`.
Consequently it is independent of the sigma-algebra generated by all events
whose triangles are vertex-disjoint from `T`; this is the required mutual
independence, not merely pairwise independence.

For each of the three vertices of `T`, at most `t-1` other triangles contain
that vertex.  Taking a union (and harmlessly overcounting triangles sharing
two vertices) gives dependency degree

`D <= 3(t-1)`.

For `t>=1`, the symmetric Lovász Local Lemma condition is

`e * k^{-2} * (D+1) <= e(3t-2)/k^2 <= 1`.

The published choice `k=ceil(sqrt(3et))+1` satisfies this, since
`k^2 >= 3et > e(3t-2)`.  In fact the `+1` is redundant for `t>=1`:
`ceil(sqrt(3et))` already works.  When `t=0` there are no bad events and one
color works; the source proof should state this separately because its
displayed `D=3(t-1)` is then negative.  This is a proof-hygiene gap only, not
a counterexample to the theorem.

With no monochromatic triangle, every color class is triangle-free.  In a
K4-free graph in which every edge lies in a triangle, the nontrivial ambient
maximal cliques are exactly the triangles.  Hence each class is admissible,
and

`beta(G) >= ceil(n/k) >= n/k`.

**Status: PASS.**

## 2. Corollary A1.1: rounding and every asymptotic term

If `Delta -> infinity` and

`t = eta * Delta^2 / ln^2 Delta`,

then the exact bound gives

`k <= sqrt(3e eta) * Delta/ln Delta + 2`.

After division by `Delta/ln Delta`, the additive error is at most
`2 ln Delta/Delta=o(1)`, uniformly in nonnegative `eta`.  Thus the displayed
coefficient `sqrt(3e eta)=2.855669... sqrt(eta)` is correct.  The source must
read this as a statement along `Delta -> infinity`; it is not a finite
identity for small `Delta`.

There is a cleaner direct inversion that does not mention `Delta`.  Suppose
`beta(G)<=h-1`, `n>=1`, and let

`q=ceil(n/(h-1))`.

Since `beta>=n/k`, one has `k>=q`.  With the published definition of `k`,

`ceil(sqrt(3et))+1 >= q`,

so `sqrt(3et)>q-2` and therefore the exact finite consequence is

`t > (q-2)^2/(3e)`.

This last squaring statement is for `q>=2`; `q=1` gives no nontrivial lower
bound.  Along the asymptotic counterexample sequence below, `q->infinity`.

Along any counterexample sequence satisfying

`n >= (c-o(1)) h^2/ln h`

for a fixed rigorous lower coefficient `c>0`, this becomes

`t_max >= (c^2/(3e)-o(1)) h^2/ln^2 h`.

Numerically,

- `sqrt(3e) = 2.855669008372142...`;
- `1/(3e) = 0.122626480390480...`;
- at the currently proved Ramsey coefficient `c=1/2`, the forced coefficient
  is `1/(12e) = 0.030656620097620...`, agreeing with the source's `~0.031`.

The source's symbol `c_R` needs repair.  The literature does not establish
that `R(3,h) ln h/h^2` converges.  A rigorous formulation can use either a
specific proved coefficient (currently `1/2`) or

`underline_c_R := liminf_{h->infinity} R(3,h) ln h/h^2`.

Writing an unknown `c_R in [1/2,1]` as a single asymptotic constant silently
assumes a limit.  This does not damage the advertised `c=1/2` consequence.

One further implicit asymptotic is sound: along such a counterexample
sequence `Delta->infinity`.  Indeed `beta>=alpha>=n/(Delta+1)` and
`beta<=h-1` imply `Delta+1>=n/(h-1)=Omega(h/ln h)`.

**Status: PASS WITH NOTATION REPAIR.**

## 3. Lemma A4.1: fractional averaging

Let `F` be the finite family of triangle-free vertex subsets and let
nonnegative weights `(x_S)_{S in F}` cover every vertex:

`sum_{S contains v} x_S >= 1`.

For `W=sum_S x_S`, double counting gives

`sum_S x_S |S| = sum_v sum_{S contains v}x_S >= n`.

For a nonempty graph `W>0`, so at least one supported set has
`|S|>=n/W`.  Minimizing `W` gives a set of size at least
`n/chi_tf^f`.  In a pure-3 graph every triangle-free set is admissible,
which proves the lemma.

No integrality-gap or rounding loss appears.  The only boundary case omitted
from the source is `n=0`, where the quotient convention would need stating.

**Status: PASS.**

## 4. From a Gibbs marginal to a fractional cover

Suppose one probability measure `mu` on triangle-free subsets satisfies the
*uniform* bound `Pr_mu(v in S)>=p>0` for every vertex.  Then

`x_S=mu(S)/p`

is a fractional triangle-free cover, since each vertex receives weight at
least one, and its total weight is exactly `1/p`.  Hence

`chi_tf^f <= 1/p` and `beta>=np`

in a pure-3 graph.  Substituting

`p=(2+delta) ln Delta/Delta`

is therefore correct (for sufficiently large `Delta`, where `p<=1`).

For a pure-3 least counterexample, `Delta<=h-1`, and `ln x/x` is decreasing
for `x>e`.  Together with `Delta->infinity` and the HHKP lower bound,

`beta >= (2+delta)n ln Delta/Delta`
`     >= (2+delta)n ln(h-1)/(h-1)`
`     >= ((2+delta)/2-o(1))h > h-1`,

a contradiction for all sufficiently large `h`.  So the Master Inequality,
if proved with one global measure and a uniform per-vertex marginal, really
would eliminate the **pure-3 face**.

An average marginal, an average link-degree estimate, or vertex-dependent
measures would not by themselves give the displayed fractional cover.  The
source labels the relevant local-occupancy statement as a target, so this is
not presently a false theorem claim, but it is an essential future audit
gate.

## 5. The scope failure at the A4.1/R2' interface

For a pure-3 graph, triangle-free color classes are admissible, and indeed
`chi_tf` coincides with clique chromatic number.  For a general least
counterexample, however, an ambient-maximal edge can lie wholly inside a
triangle-free class.  Such a class is **not** admissible.  Therefore neither

`beta >= n/chi_tf`

nor its fractional analogue holds outside the pure-3 face.

The two-vertex graph `K2` is already an exact counterexample to such an
extension: its whole vertex set is triangle-free, so `chi_tf^f(K2)=1`, while
its unique edge is an ambient-maximal clique and `beta(K2)=1<2/1`.

This invalidates the broad statements at `PROGRAM_ALPHA.md:3-6` and the
unqualified “for all large h” reading at `PROGRAM_ALPHA.md:289-290`.  It is
especially material because the campaign's own corrected TCG analysis says
that any `(50,11)` witness must contain maximal edges.  The M-burden theorem
is a useful constraint but does not yet convert a fractional triangle-free
cover into a fractional cover by admissible sets.

A full-#151 route needs one of:

1. a fractional cover directly by admissible sets;
2. a clique-coloring bound (including maximal-edge constraints);
3. a theorem eliminating/reducing the maximal-edge system; or
4. an explicit argument paying for maximal edges while preserving the
   required constant.

Until then, Program Alpha is a pure-3 subprogram, not a full asymptotic
resolution program.

**Status of A4.1 itself: PASS.  Status of the claimed global use: FAIL AS
STATED.**

## 6. R2' constant chain

The published JMRS theorem gives, for every `epsilon>0` and sufficiently
large `Delta`,

`chi_c(G) <= (1+epsilon)Delta/ln Delta`

for every graph.  More generally, suppose a bound with constant `C+o(1)`
holds on the least-counterexample class.  Since a clique-color class is
admissible,

`beta >= n/chi_c`.

Using `Delta<=h-1`, monotonicity of `ln x/x`, and `Delta->infinity`, a least
counterexample would force

`R(3,h)=n <= (C+o(1))h^2/ln h`.

Thus `C<underline_c_R` contradicts the definition of
`underline_c_R=liminf R(3,h)ln h/h^2`.  In particular `C<1/2` is a safe
target under the March 2026 HHKP preprint.  This chain is valid for clique
coloring and does cover maximal edges; it is not interchangeable with the
triangle-free fractional-cover chain.

The ledger formula `c_H=1/sqrt(2c_R)` is only conditional on an actual
asymptotic `R(3,h)~c_R h^2/ln h`.  Without existence of that limit it should
be replaced by corresponding liminf/limsup inequalities.  This heuristic
notation is not load-bearing for the strict `C<1/2` implication.

- Hefty--Horn--King--Pfender, *Improving R(3,k) in just two bites*, revision
  dated 22 March 2026: `R(3,k)>=(1/2+o(1))k^2/log k`, and the paper describes
  the `1/2` coefficient as conjecturally tight:
  https://arxiv.org/abs/2510.19718
- Joret--Micek--Reed--Smid, *Tight Bounds on the Clique Chromatic Number*,
