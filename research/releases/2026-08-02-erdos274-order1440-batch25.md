# Exact 25-group order-1440 frontier for Erdős #274

Published: 2 August 2026

## Audited result

For 25 explicitly identified solvable non-supersolvable groups
`SmallGroup(1440,gid)`, an exact normalized search found no partition into
more than one right coset of subgroups having pairwise distinct indices.
The IDs are recorded in `experiments/erdos274_order1440/README.md` and in the
machine-readable `batch25_results.json`.

This is an easiest-first finite batch. It does **not** check every group of
order 1440, improve the unconditional all-groups order bound, or solve the
Herzog--Schönheim conjecture / Erdős Problem #274.

## Verification record

Every admissible distinct-index reciprocal pattern was exhausted with zero
search caps. Two groups completed through recorded disjoint pattern ranges;
one of the slower groups, ID 1625, also passed a clean uninterrupted replay
covering all 5,402 patterns and 3,004,731 search nodes.

The normalization is lossless: right translation makes one chosen coset an
identity-containing subgroup, and inner conjugation moves that subgroup to a
conjugacy-class representative while preserving right cosets. The arithmetic
filters are necessary conditions from the published small-groups analysis.

The package contains the GAP exporters, exact Python search, group-selection
analysis, per-input SHA-256 hashes, complete result summaries, the clean replay
log, and commands for regeneration.

The result trusts GAP's SmallGroups and coset data, the exported TSVs, and the
audited Python traversal. It is an exhaustive computation for the named
groups, not a Lean theorem or a retained proof-certificate theorem.

## Recency boundary

An announcement-level search on 2 August 2026 found the live problem still
open and found no matching public verdict for these 25 named groups. Recent
work proves the conjecture for simple and symmetric groups; the present batch
instead consists of solvable non-supersolvable groups. This search is evidence
against a known collision, not an absolute priority claim.
