# Generator and catalogue provenance

## Primary canonical generator

Source: Brendan McKay and Adolfo Piperno, official nauty/Traces page,
<https://users.cecs.anu.edu.au/~bdm/nauty/> (the package states that `geng`
generates non-isomorphic graphs).  Version `2.9.3` was downloaded from the
official second mirror:

```text
https://pallini.di.uniroma1.it/nauty2_9_3.tar.gz
```

Archive SHA-256:

```text
9FC4EDAE04F88A0F5883985BE3B39CF7F898FD6CC96E96B9EE25452743CC1B5B
```

Selected source hashes:

```text
12BBA376483782AE40B132E0B66F42CBBBF3ACB6C2468F8C0E33CCDD505FC2D0  geng.c
D4CA7E89C5500E8A242C7A088C882AC1D11CD5738B51FD718F381F67BE35DD04  nauty.c
```

The source was configured and compiled inside the already-local Linux/amd64
image with digest

```text
sha256:c9de640c09ecd5223afa907847a97a7397f11a5b45970095c967c4bb99f40b5c
```

using

```sh
./configure
make -j2 geng
```

The resulting 166,552-byte `geng` executable has SHA-256

```text
54905DF2D5262992CE80ABABA785FF5A41B223A2A6B03C1274D5A9BE4A9A181A
```

For each even `n` through 20, the exact command class was

```sh
./geng -c -d3 -D3 n (3*n/2) cubic_nNN.g6
```

Thus every output is connected and simple, every degree is exactly three,
and `geng` supplies one representative per isomorphism class.  The scanner
nevertheless reparses every record and independently checks simplicity,
degree, and connectedness.

## Independent census/count source

The Flinders Hamiltonian Cycle Project graph database publishes independent
Hamiltonian and non-Hamiltonian connected cubic counts through order 20 and
states that its graphs were originally produced by Meringer's GENREG:

<https://sites.flinders.edu.au/flinders-hamiltonian-cycle-project/graph-database/>

Its cited generator paper is M. Meringer, *Fast Generation of Regular Graphs
and Construction of Cages*, Journal of Graph Theory 30 (1999), 137--146.
The primary `geng` run agrees exactly with every Flinders count:
