# Root order-12 certificate slices for Erdos #149

This directory contains the generators and metadata for the 22-edge and
triangle-containing 23-edge slices. The combined theorem, independent audits,
remaining triangle-free cases, reproduction instructions, and downloadable
certificate archive are in
`../erdos149_long_horizon_max_2026-08-03/README.md`.

These are components of a bounded order-at-most-12 theorem, not a resolution
of Erdos problem #149.
