# Preprint build

`cubic_abundance.tex` is the focused public-review version of the incidence
kernel theorem and its finite-kernel closure in
`MILESTONE_2_INCIDENCE_KERNEL.md` through
`MILESTONE_4_UNIVERSAL_PLUS6.md`, together with the edge corollary in
`MILESTONE_1_AUDIT.md`. It is a partial structural result, not a resolution
of Erdős problem #64.

Build from the repository root with the bundled LaTeX workflow. The PDF must
be visually checked before any arXiv or Zenodo upload.
