# Certificate package: bipartite part-size bound for Erdős problem #64

Release date: 3 August 2026

## Certified theorem

Every finite simple bipartite graph of minimum degree at least three that
contains no cycle of length 4, 8, or 16 has at least 20 vertices in each
bipartition class.

Consequently, every bipartite counterexample to the Erdős--Gyárfás
conjecture has at least 20 vertices in each class. This is a restricted
computational theorem, **not** a solution of Erdős problem #64.

The stronger part-size statement is plausibly new after a targeted priority
search, but specialist confirmation is still pending. The weaker total-order
40 corollary is implicit in prior public extremal data and is not claimed as
new. The 38-vertex graph used during discovery is Gordon Royle's 2009 graph
`F038A`, not a new construction.

## Files

- `sigma14-18-cnf-drat-results.zip` contains independently regenerated CNFs,
  ASCII DRAT proofs, and result manifests for fixed side sizes 14 through 18.
- `sigma19-cnf-drat-audits.zip` contains the frozen side-19 CNF, the fresh
  single-writer binary DRAT proof, solver and checker transcripts, all 512
  audited C16 blocking clauses, and the scripts and JSON audits that bind the
  final CNF to the intended incidence problem.

The side-19 proof was generated by CaDiCaL 1.9.5 and replayed independently
with Linux `drat-trim`, which read all 230,688,966 proof bytes and returned
`s VERIFIED` after 160,990,667 resolution steps.

## Reproduction

Extract an archive without changing filenames. The JSON result manifests
bind each CNF, proof, solver, checker, and transcript by SHA-256. Replay an
ASCII proof with `drat-trim CNF PROOF`. The side-19 proof is binary DRAT and
must be replayed by a build that supports binary input; the included Linux
transcript records a full successful replay. A native Windows checker build
used during the campaign misparsed the binary format after 622 bytes, so its
negative diagnostic is preserved but is not part of the certification.

For the complete mathematical reduction, scope, and correction record, see
`PURE19_C16_EXCLUSION_2026-08-03.md` and
`BIPARTITE_SIDE20_THEOREM_2026-08-03.md` in the repository at this release
tag.
